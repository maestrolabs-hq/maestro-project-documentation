# Roadmap

This roadmap presents capability states. It is not a release promise or a
second repository backlog.

## Built

<span class="maestro-status" data-status="built">Built</span>

- Repository governance can compare the organization against a versioned
  baseline and apply the setting changes it owns.
- Pi configuration can be captured and managed from its owning repository.
- The core workspace provides the protocol and CLI foundations while stating
  that its commands are not implemented.

## In progress

<span class="maestro-status" data-status="in-progress">In progress</span>

- The shared Maestro knowledge book and its checked public rendering.

## Designed

<span class="maestro-status" data-status="designed">Designed</span>

- Supervisor residency, delegation, and accountability.
- Durable ledger states, retry, delivery, and dead-letter behavior.
- The pi memory shim and its lifecycle-event boundary.

## Exploring

<span class="maestro-status" data-status="exploring">Exploring</span>

- A gated idea-to-production pipeline.
- A future `maestro idea` command surface after the manual workflow is proven.

Follow [What exists today](../overture/current-reality.md) for sourced status
statements and repository links.
