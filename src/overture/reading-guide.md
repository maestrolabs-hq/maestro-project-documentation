# How to read this site

## Status is explicit

The site uses four values only:

- <span class="maestro-status" data-status="built">Built</span> means working
  behavior exists at the cited revision.
- <span class="maestro-status" data-status="in-progress">In progress</span>
  means implementation is active.
- <span class="maestro-status" data-status="designed">Designed</span> means a
  reviewed design exists without the claimed implementation.
- <span class="maestro-status" data-status="exploring">Exploring</span> means a
  direction is under consideration and is not a commitment.

## Evidence is opt-in

A framed claim with a source and verification date is machine-checked. Its
source points to an immutable commit and line range. Ordinary paragraphs are
reviewed prose and must not be read as machine verification.

## Ownership stays local

Repository pages in this book explain relationships and link outward. Follow
their primary links for implementation details, backlogs, runbooks, and
recorded decisions. If this book and an owning repository disagree, the owning
repository is authoritative and this book needs correction.
