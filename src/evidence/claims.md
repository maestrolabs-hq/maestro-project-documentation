# Verified claims

A claim block is opt-in machine verification. `sitecheck` requires its status,
verification date, and immutable GitHub commit permalink with a line anchor.
It does not classify ordinary prose.

## Claim index

- [Organization purpose](../index.md)
- [Current implementation boundaries](../overture/current-reality.md)
- [Proved gates](../method/proved-gates.md)
- [Decisions beside code](../method/decisions.md)
- [Rebuild target](../method/rebuilding.md)

A passing check proves that claim metadata is immutable and well-formed. It
does not make old evidence current. Reverification requires a deliberate source
revision and date update.
