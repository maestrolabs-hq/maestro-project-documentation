# Principles

Maestro's method turns qualities into things that can be checked.

## Rebuild instead of remember

Machine state belongs in a repository and a repeatable command, not in one
operator's memory. See [Rebuilding from source](rebuilding.md).

## Record decisions where they apply

A hard-to-reverse decision belongs beside the code or configuration it governs.
See [Decisions beside code](decisions.md).

## Prove a gate can fail

A green check is evidence only after the fault it exists to catch has made it
red. See [Proved gates](proved-gates.md).

## State uncertainty honestly

The [current reality](../overture/current-reality.md) and
[roadmap](../delivery/roadmap.md) keep built work apart from designs and
exploration. Closing a gap starts with naming it.
