# Decisions beside code

A durable decision is recorded where a future change will encounter it.

<div class="maestro-claim" data-status="designed" data-source="https://github.com/maestrolabs-hq/maestro-core/blob/3b841b6656b6ff0877d6785ef0e1eb8f0f792455/NORTHSTAR.md#L16-L17" data-verified="2026-09-01">
  <p>The estate commits to recording a decision beside the thing that enforces it, using an ADR rather than relying on conversation or commit history alone.</p>
</div>

This book links decisions across repository boundaries; it does not relocate
them. The [ADR index](../evidence/adrs.md) is therefore a directory of primary
sources, not a second decision log.
