# Rebuilding from source

Reproducibility replaces remembered setup with versioned state and a command
that can be exercised again.

<div class="maestro-claim" data-status="designed" data-source="https://github.com/maestrolabs-hq/maestro-core/blob/3b841b6656b6ff0877d6785ef0e1eb8f0f792455/NORTHSTAR.md#L13-L14" data-verified="2026-09-01">
  <p>The estate's stated test for machine rebuildability is a clean machine and one command.</p>
</div>

The status is deliberately `designed`: the north star also records that the
clean-machine restore target is not measured today. The target guides
[maestro-pi-config](../estate/maestro-pi-config.md); passing evidence must still
come from a real restore.
